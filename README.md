**Project Goal**

The goal of this project is to analyze the key drivers of customer churn in a telecom company and to build a predictive model that identifies customers at high risk of leaving. The final output is an interactive Power BI dashboard that visualizes historical churn patterns and displays the results of the predictive model.

**Methodology & Workflow**

This project follows a three-stage workflow, utilizing SQL for data preparation, Python for predictive modeling, and Power BI for data visualization.

**1. SQL: Data Cleansing and Preparation ⚙️**

**Initial Data Load & EDA:** The raw telecom dataset was first loaded into a SQL database. Initial exploratory data analysis (EDA) was performed to check Key Performance Indicators (KPIs) like total customers, overall churn rate, and revenue metrics.

**Data Cleansing:** Null values and inconsistencies in the dataset were identified and cleaned to ensure data quality.

**View Creation:** A final, clean dataset was created by joining multiple tables (e.g., customer demographics, services, and account details). This consolidated data was stored in a SQL view named join_data for easy and efficient access by other tools.

**2. Python: Predictive Modeling 🤖**

**Data Import:** The clean data was imported from the join_data SQL view into a pandas DataFrame.

**In-depth EDA & Preprocessing:** Further EDA with libraries like Matplotlib and Seaborn was conducted to visualize relationships between features and churn. The data was then preprocessed for machine learning, which included:

Encoding categorical variables (e.g., Contract, PaymentMethod).

Scaling numerical features (e.g., tenure, MonthlyCharges).

**Model Building & Prediction:** A classification model (like Logistic Regression or Random Forest) was trained on the preprocessed data to predict the likelihood of churn for each customer. The model's predictions were then saved to a separate file (prediction_data.csv).

**3. Power BI: Visualization and Insights 📊**

**Data Integration**: The original clean dataset from SQL was imported into Power BI and merged with the prediction_data.csv file generated by the Python model.
